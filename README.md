## Description
Application Python en console permettant de gérer des tâches quotidiennes.
Tout le code se trouve dans un seul fichier : `main.py`.

## Fonctionnalités
- **1 – Ajouter une tâche** : demande un titre (une saisie vide est refusée).
- **2 – Afficher les tâches** : liste les tâches numérotées, ou affiche un message si la liste est vide.
- **3 – Rechercher une tâche** : affiche les tâches dont le titre contient le mot-clé saisi.
- **0 – Quitter** : ferme le programme. Toute autre option affiche un message d'erreur.

## Étapes réalisées
1. Création du programme `main.py` (menu, boucle `while`, liste de tâches).
2. Ajout de la fonction de recherche.
3. Rédaction du `README.md`.
4. Initialisation de Git, commits successifs et publication sur GitHub (`git push`).

## Exécution
1. Ouvrir le dossier du projet dans VS Code.
2. Ouvrir `main.py`.
3. Cliquer sur le bouton **Run Python File** (triangle en haut à droite).
4. Utiliser le menu dans le terminal.
